# Machine Learning Research Assignment

## Overview

This repository contains my Machine Learning Research Assignment, completed as part of the BrightLearn Data Science programme.

The assignment combines theoretical research with practical Python exercises to develop an understanding of Machine Learning concepts and their application in data analysis and predictive modelling.

The practical component uses the Titanic dataset to demonstrate data preparation, exploratory data analysis and techniques used to prepare data for Machine Learning.

## Learning Objectives

The assignment explores the following areas:

- **Introduction to Machine Learning:** Understanding Machine Learning and its relationship with Artificial Intelligence, Deep Learning and Data Science.
- **Machine Learning Approaches:** Exploring supervised and unsupervised learning, including their differences and applications.
- **Data Preparation:** Identifying and handling missing values, duplicate records and incorrect data types.
- **Exploratory Data Analysis:** Examining datasets using descriptive statistics and visualisations.
- **Outlier Detection:** Applying statistical techniques such as the Interquartile Range (IQR) to identify potential outliers.
- **Feature Engineering:** Understanding how data can be transformed and prepared for analysis and modelling.
- **Data Relationships:** Using correlation analysis to explore relationships between numerical variables.

## Practical Implementation

The Jupyter Notebook demonstrates practical data preparation and analysis using Python.

The tools and libraries explored include:

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

The Titanic dataset is used to investigate passenger information and survival patterns.

The practical work includes:
- Inspecting the dataset and understanding its structure.
- Identifying missing values and duplicate records.
- Handling missing numerical and categorical values.
- Encoding categorical variables.
- Scaling numerical features.
- Exploring outliers using the IQR method and boxplots.
- Examining correlations between variables.
- Preparing training and testing datasets.
